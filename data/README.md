# Data
This directory contains publicly available sequencing data that can be found on NCBI.

## Hi-C sequencing data available from NCBI accession PRJNA1453590:
- `pb420_hic_r1.fastq.gz`
- `pb420_hic_r2.fastq.gz`

## ONT sequencing data available from NCBI accession PRJNA1451928:
- `PB420_ONT_pass.20251006.fastq.gz`

## Short-read whole-genome DNA sequencing data available from NCBI accession PRJNA1453487:
- `PB420_POOLRET57_1N_1R.fq.gz`
- `PB420_POOLRET57_1N_2R.fq.gz`
- `PB420_SR_merged.fastq.gz` - this file is produced by merging `PB420_POOLRET57_1N_1R.fq.gz` and `PB420_POOLRET57_1N_2R.fq.gz`

## PacBio HiFi sequencing data avalable from NCBI accession PRJNA1451928:
